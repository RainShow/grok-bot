# Grok City

Grok City 是一座可切换楼层的 3D 办公室。底栏是 Grok Bot 花名册，读 `public/fleet.json`（样例，失败时用内嵌同一份）。点楼层会推近到剖开的那一层：夜班作战、内容运营、研究写作、大厅。book 离线，坐在大厅。机密层是夜巡。点击 bot 仍走原来的 `grokbot://` 深链。

审批停在浏览器里。批准、编辑、拒绝都不会发到 X、抖音或任何服务器。

## 本地看

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 类型检查 + 生产包，产物在 dist/
```

`dist/` 用了相对路径，可以整目录放到站点的子路径（例如 `/city/`）。不要覆盖站点根目录。说明写在 `dist/CITY.txt`。

可选：`?at=21` 从晚上九点开班。

## 点哪里

1. 打开 `/`。总览是 Grok City 的玻璃楼和园区。左上是楼层，顶上是工作中 / 等待，数字跟花名册样例一致。
2. 点「夜班作战」或其他楼层。镜头弹簧推近，上面的楼层上移淡出，这一层剖开展示桌椅和 bot。
3. 悬停 bot 看名字、职责和手头的事。点 bot，右侧钉住详情，「打开对话」走深链，id 可以复制。
4. 底栏花名册可以滚动。点一张卡会切到那一层并打开同一张详情。
5. 底下活动气泡在走样例夜班。点「夜班」展开原来的操作面板，点「汇总」看这一夜。面板里的 `1x / 2x / 4x` 可以加快。
6. 点「机密」进入夜巡。画面转红，中间提示「准入通过」。proto、analysis、Grok 在里面，深链不变。
7. 窄屏大约 375px：楼层菜单横向滚动，点按区不小于 44px，可以拖拽和平移 3D 场景。
