# 不可思议之城

夜班仪表盘。六个内容机器人在一座夜里的城里把一条稿子从拆镜送到发报：拆镜 → 钩子 → 平台 → 归档 → 门卫 → 发报。城中心是借腹南瓜城，广场边上立着七道门：时间、因果、重力、知觉、尺度、形体、路径。

审批停在浏览器里。批准、编辑、拒绝都不会发到 X、抖音或任何服务器。

## 本地看

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 类型检查 + 生产包，产物在 dist/
```

`dist/` 用了相对路径，可以整目录放到站点的子路径（例如 `/city/`）。不要覆盖站点根目录。说明写在 `dist/CITY.txt`。

可选：`?at=21` 从晚上九点开班。

## 点哪里

1. 打开 `/`。抬头是「不可思议之城 · 夜班」，中间是夜城，底下是六个机器人。
2. 看拆镜把稿子沿街送去钩子房。`city.log` 和右侧浏览 / 关注 / 分享会自己走。
3. 左侧出现「需要你」时，选一道门（时间 / 因果 / 重力 / 知觉 / 尺度 / 形体 / 路径），或批准借腹南瓜城那句「天亮前谁也别走」。四十秒没人应，城会自己选「时间」。
4. 稿子走到门卫，点批准、编辑或拒绝。门卫不会自己放行。
5. 任务板和底栏卡片跟着变。发报写的是「模拟发出」。
6. 点底下「汇总」，或等六条额度满 / 点「收班」，看这一夜的浏览、关注、分享。

头顶 `1x / 2x / 4x` 可以加快。
